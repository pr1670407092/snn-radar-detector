## 三、六项证据分别证明了什么

| 编号 | 证据 | 证明的结论 |
|---|---|---|
| E1 | 核心仿真 8 例全 PASS | 加速器算得对（判决 1 1 1 1 0 0 0 0） |
| E2 | 板级仿真 8 例、pass_count=8 | 板级外壳（ROM/状态机/LED）接得对 |
| E3 | 7 条 readmem 全部成功 | **ROM 内容真的进了位流**（这是最容易被忽略的一环） |
| E4 | JTAG 探测到 XC7A200T | 位流给对了芯片（不是 100T） |
| E5 | 下载记录 | 位流确实写进了 FPGA |
| E6 | DONE=1、CRC_ERROR=0 | FPGA 配置成功且数据无错 |
| E7~E10 | 时序/资源/DRC/功耗 | 设计能稳定跑在 100 MHz |

**逻辑闭环**：E4+E5+E6 证明「位流正确进了板子」；E1+E2+E3 证明「位流里的逻辑和数
据是对的」。两者合起来才是完整证据。

## 四、⚠️ 还差一项：LED 实拍照片

**这一项必须由你在板子前完成，我无法代做。**

当前证据能证明位流正确载入，但「8 个用例在硬件上真的判对了」这一句，
最直接的凭据是板上 LED。步骤：

1. 板子保持上电、JTAG 已下载完成
2. 按一下板上的 **RESET** 键
3. 等约 1 秒（单例 5.82 ms，8 例约 47 ms，早就跑完）
4. 拍下 4 个 LED 的照片

**判读：**

| LED | 引脚 | 正常表现 |
|---|---|---|
| LED0 | W7 | 已熄灭（推理结束） |
| LED1 | Y7 | **常亮**（8 例跑完） |
| LED2 | Y8 | 熄灭（第 7 例是负例） |
| LED3 | V9 | **常亮 = 8/8 全对** |

只要照片里 **LED1 和 LED3 同时亮、LED0 和 LED2 灭**，就是完美通过。

> 如果 LED 全反（该亮的不亮、该灭的亮），说明这颗板的 LED 是低电平点亮，
> 把 `rtl/board_top.v` 里 `LED_ACTIVE_LOW` 改成 `1'b1` 重新构建即可（约 60 分钟）。

**如果要机器可读的硬件证据**（不靠眼睛看）：可以加一个 VIO 调试核，
通过 JTAG 直接读出 `pass_count` 和 8 位判决串。需要重新实现一次，告诉我就行。

## 五、老师可能问的问题，怎么答

**Q：你怎么证明是跑在这块板上，不是仿真？**
A：看 E4/E5/E6 —— JTAG 读到的器件 IDCODE 是真实硬件返回的，`DONE=1` 是 FPGA 内部
配置寄存器的回读值，仿真是产生不出这些的。另附 LED 照片。

**Q：为什么器件是 200T，不是资料上写的 100T？**
A：以 JTAG 实测为准。IDCODE `0x13636093` = XC7A200T。达芬奇Pro 核心板可换，
卖家资料常按 100T 写。顺带一提，200T 没有 `fgg484` 封装，正确字符串是
`xc7a200tfbg484-2`。

**Q：8/8 通过是怎么保证的？**
A：两层仿真：核心层对照位精确的 Python 参考模型，板级层验证 ROM/状态机/LED。
并且板上用的 `.mem` 数据与仿真用的**逐字节核对一致**，所以仿真结论可代表上板。
最终由 LED3 点亮确认。

**Q：你改动了原工程的什么？**
A：只动板级外壳（引脚约束、器件型号、LED 极性开关、下载脚本），
加速器核心 RTL 逻辑**一行未改**。另外修复了一个原工程的 1 位宽 ROM 缺陷，
详见报告第 6 节——这是本次工作最有价值的部分。

**Q：遇到的最大困难是什么？**
A：那个 1 位宽 ROM 缺陷。它仿真能过、综合只给 warning，但硬件上 ROM 全是 0，
会导致自检永远只有 4/8 通过。靠补写板级测试台 + 逐条核查综合日志才定位到。

## 六、重新生成报告

报告里的数字都来自实际日志。若重新构建后要更新报告，对应关系：

| 报告里的数字 | 来源文件 |
|---|---|
| LUT/FF/BRAM/DSP/IOB | `build/board/util_board.rpt` |
| WNS/WHS/TNS | `build/board/timing_board.rpt` |
| DRC 违规数 | `build/board/drc_board.rpt` |
| 功耗/结温 | `build/board/power_board.rpt` |
| readmem 条数 | `build_board.log` 中 `Synth 8-3876` / `8-2898` |
| DONE 位 | `verify_board.log` |
