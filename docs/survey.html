00执行摘要：六个结论

  1. 雷达 SNN 已经从“分类”走到“检测 + PFA 控制”。GRSL 2025 的 RSN 用 time-frequency graphs（TFG）+ 残差脉冲网络 + 膜电位读出，在 IPIX 上做到 PFA 1e-3 时 PD 0.8266，能耗约为 ResNet18 的 70%。这是我们引用的核心论文。
  2. 对本任务，最有效的不是更深的 MLP，而是“时频图 + 2D 残差脉冲 CNN”。本地 float SNN 99.72%、int8 参考 99.62%，显著高于 1D 纯 SNN 的 96.64%；离 ANN 上界 99.83% 只差 0.11 个点。
  3. “SNN 做主力”可以落到 7020。64-lane 2D 引擎在 100 MHz 实现，8/8 决策通过，LUT 14,946（28.1%）、BRAM 98/140（70%）、功耗 0.584 W；单次 9.01 ms。
  4. 低延迟仍然是 1D 8-bit 256-128 的天下。96.64%、1.77 ms、BRAM 36.5/140，且 RTL 与 Python 逐计数 bit-exact；2D RSN 是“精度优先”的版本。
  5. 纯 SNN 的瓶颈在训练 recipe，不在“能不能跑”。朴素 QCFS 原型只有约 51%（λ/θ/v0/T 没对齐）；direct BPTT + SEW 残差 + 膜电位读出才是 2D RSN 能到 99.6% 的原因。
  6. 研究空白很清楚：没有公开的 7020 雷达 SNN 实现；IEEE 雷达论文全文大多闭源；真实 IPIX/实测数据、event-driven 卷积、2D bit-exact 都还没做完。

2.1 GRSL 2025 RSN：为什么它最值得我们跟

RSN 的关键不是“用了 SNN”，而是三件事同时成立：

  • 输入选对了：time-frequency graph 把 LFM 的 chirp 线、杂波和多普勒都放在一张 2D 图里，2D 卷积比 1D 幅度谱更有分辨力；
  • 骨干选对了：残差连接让脉冲网络能加深，同时不把梯度/膜电位炸掉；
  • 读出选对了：用最后层膜电位（而不是只看 spike count）做统计量，再在验证集负样本上标定 PFA。对雷达检测，这是“可部署”的关键。

我们在 9.9/9.10 节按这条路线做了本地复现：STFT 32×32 TFG + 2D 残差 spiking CNN（6 层卷积全部 spiking，SEW-ADD，T=4），float 99.72%、int8 99.62%；PFA 1e-3 时 PD 99.47%、实测 PFA 0.05%。这不是 IPIX 的 0.8266，但说明“TFG + RSN”在本任务上成立。

2.2 其余雷达路线：一句话判断

  • 神经形态 ADC + 异步 HRRP：解决“采样功耗/带宽”，不是“检测算法”；适合做前端，不适合替代我们的 2D 检测骨干。
  • Spiking transformer / SSM：在 HAR/AMR 上能出高精度，但参数量、T、注意力/扫描结构对 7020 不友好；除非做 4-bit + 大 BRAM + 多帧，否则不优先。
  • 轻量 TF-Spkformer：题名和我们的方向最接近，但摘要为空、没有可引用指标；只能作为“同类工作存在”的证据。
  • FMCW Fourier SNN / spiking resonators：更偏前端/频域特征提取；可以作为片上 FFT/STFT 之后的第二级，但不是完整检测器。

3.1 转换 vs 直接训练：我们踩过的坑

转换（QCFS/PASCAL/Fast-SNN）：训练 ANN 容易、精度上限高；但 SNN 的 λ、θ、初始膜电位、T 必须严格对齐，否则会出现“ANN 97%、SNN 51%”的断崖。我们手写 QCFS 原型就踩了这个坑。
直接训练（BPTT + surrogate）：不需要对齐转换公式；但训练更不稳定、对 T/SEW/读出敏感。我们最终在 2D TFG 上用 SEW-ADD + 膜电位读出 + T=4 做到 99.72%，说明“直接训练 + 残差”是可行的。

3.2 为什么 2D RSN 比 1D MLP 强

1D MLP 把 512 点 FFT 幅度谱压成向量，丢掉了“频率随时间怎么变”的结构；2D TFG 保留了 chirp 的斜线、杂波的条纹和多普勒的局部结构。对 LFM 回波，这是决定性的：同一套 28k 参数，2D 残差 SNN 能到 99.7%，1D 三层 MLP 只有 96.6%。这不是“网络更大”，而是输入表示更适合 2D 卷积。

深度/宽度消融（本地）：简单集 6L/8L/W24 = 99.72/99.49/99.61%；难集（SNR −10…0、CNR 8…18、K 杂波/尖峰/干扰/缺失/失配）= 76.89/76.98/76.68%（AUC 0.844/0.840/0.843；PFA 1e-2 时 PD 46.7/46.1/48.0%）。加层/加宽在简单集和难集都没有明显收益；简单集饱和，难集才是真实瓶颈。下一步优先 T=8、特征/预处理、真实 IPIX；LUT/FF 余量适合 128-lane 提速，不是堆层。

3.3 Spiking U-Net：为什么没继续

Spiking U-Net 适合“输出干净 range profile / 做杂波抑制 / 目标定位”，需要 per-bin 掩码标签；当前任务是二元检测，TFG RSN 直接分类已经到 99.7%，没有必要引入 U-Net 的编码器-解码器和逐 bin 监督。U-Net 留作后续“杂波抑制/定位”的备选。

04硬件：7020 上怎么把 SNN 跑起来

4.1 SNN 硬件的五个关键点

  • 无乘法器：输入是 0/1 spike，权重是 int8；乘加退化成“条件加”，DSP 可以几乎不用（我们的 2D 引擎只用了 2 个 DSP 做 FC）。
  • 膜电位是状态：每层每个神经元要存 24-bit 膜电位；2D 引擎 73,728 个神经元 → 48 BRAM，这是 BRAM 的主要开销。
  • 权重打包：每 32 个 int8 打成 256-bit 字，一次读一拍；1D 32-lane 引擎的 BRAM 深度/位宽权衡决定了 512 神经元/层的上限。
  • 脉冲稀疏性：理论上 event-driven 可以跳过零 spike；我们的 2D 引擎目前是 dense（每 tap 都算），event-driven 1.57 ms 仍是估算。
  • 流水：LIF/计数/FC 都要拆两级，否则 100 MHz 收不住；我们的 WNS 从 −3.268 收到 +0.070，靠的就是这些流水。

4.3 2D 时频 RSN：算法与 RTL

算法：STFT 32×32 TFG（64 点 STFT，hop 16）→ 6 层 2D 残差 spiking CNN（SEW-ADD，BN，LIF，膜电位读出，direct BPTT），T=4，28,146 参数。float 99.72%，int8 99.62%。

RTL：一个 64-lane 通用 2D 卷积引擎，按层加载配置（Cin 1/16/32、Cout 16/32、stride 1/2、SEW 源、权重/偏置/膜电位基址）；3×3 三行 line buffer；一个 tap/cycle；int8 权重、24-bit 膜电位；全局 max + int8 FC 32→2。100 MHz 实现：WNS +0.070 ns、0 失败端点、0.584 W、9.01 ms/次。

4.4 和文献硬件比，我们处在哪

  • 公开的雷达 SNN 论文大多只报 GPU/神经形态芯片的“理论能耗/相对能耗”，没有 7020 级 FPGA 的 LUT/BRAM/时序；我们的 100 MHz 2D 引擎是少见的“可综合 + 8/8 决策 + 资源/功耗”的完整数据点。
  • PYNQ-Z2 QCSNN（2026）是少数 FPGA SNN 工作，但任务/网络不同；不能直接比精度。
  • 神经形态 ADC + SNN（RadarConf 2024）解决的是采样前端；我们的 2D 引擎解决的是“拿到 TFG 之后”的检测骨干，两者可以组合。

05讨论：什么有效，什么无效，下一步做什么

5.1 有效的

  • TFG + 2D 残差 spiking CNN：99.72% float / 99.62% int8；明显优于 1D MLP。
  • SEW-ADD + 膜电位读出 + T=4：direct BPTT 稳定，PFA 可控。
  • 64-lane 通用 2D 引擎：100 MHz、8/8、BRAM 98/140、0.584 W；六层共享一套 MAC/LIF。
  • 1D 8-bit 256-128：1.77 ms、bit-exact，低延迟首选。

5.2 无效 / 不推荐

  • 4-bit 857k 大网络：96.50%、PFA 2.48%、4.755 ms；更大更慢，不推荐。
  • 朴素 QCFS 手写实现：约 51%；recipe 不对齐，不能当结论。
  • 混合方案：97.94%，但 SNN 只有 2,112 突触，不能算“SNN 主力”。
  • Spiking U-Net：对二元检测没有必要；留给杂波抑制/定位。

5.3 研究空白

  1. 没有公开的 7020 雷达 SNN 实现：文献要么算法 + GPU，要么神经形态芯片；缺少 LUT/BRAM/时序/功耗的完整可复现数据。
  2. 真实数据缺口：我们的 99.72% 是合成 LFM + 杂波；IPIX/实测海杂波上的泛化还没验证。
  3. Event-driven 卷积：1.57 ms 是按平均脉冲率估算，尚未在 RTL 实现；dense 版 9.01 ms。
  4. 2D bit-exact：跨 t 行缓冲还有 5 字/43 bit 差异；1D 已 bit-exact。
  5. 100 MHz 余量：WNS +0.070 ns 很薄；换 P&R 可能掉负，需要 guardband/再流水。

06结论

对“雷达回波有无目标 + 7020 + PL-only”这个任务，最值得讲的故事不是“我们把一个 MLP 塞进了 FPGA”，而是：时频图 + 2D 残差脉冲网络把纯 SNN 从 96.6% 推到 99.7%，并且真的做成了 100 MHz、8/8 决策、0.584 W 的 64-lane 2D 卷积引擎。

文献侧，GRSL 2025 RSN 给了“TFG + 残差 spiking + 膜电位 PFA”的路线；我们把它在合成数据上复现到 99.7%，并补上了“7020 上怎么放、怎么流水、资源/时序/功耗是多少”这一块。1D 8-bit 256-128 仍然保留为低延迟/bit-exact 的基线；4-bit 大网络和混合方案作为对照，不推荐作为最终版本。

下一步优先级：（1）跨 t 行缓冲 bit-exact；（2）event-driven 2D 卷积（目标 ~1.6 ms）；（3）真实 IPIX/实测数据；（4）PL 上板与片上 STFT。100 MHz 已经收敛，但 WNS 余量很薄，上板前建议再做一轮 retiming/guardband。
